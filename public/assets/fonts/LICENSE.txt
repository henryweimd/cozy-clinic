Baloo2.ttf — Baloo 2 variable font (weight 400-800), rounded casual
display face used for ALL in-game text (title, subtitle, nametag,
dialogue bubble).

Designer: Ek Type (Ekta Shah).

Vendored into the repo so the demo works FULLY OFFLINE — no CDN,
no runtime webfont fetch. Phaser draws it via canvas fillText after
the main.ts document.fonts.load() gate; fallback stack is
'Comic Sans MS', 'Chalkboard SE', system-ui, sans-serif.
